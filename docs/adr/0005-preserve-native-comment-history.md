# 保留原生评论消息并追加更正记录

现有外部 provider 接口不支持任意替换或删除原生 user/assistant 历史消息，因此不能同时保留原生消息语义并承诺远端编辑、删除原位反映到这些记录。
首版选择原生消息：远端评论编辑时追加更正内容，删除时追加删除提示，保留原消息，而不将所有评论改为可替换的插件卡片。
状态变化与更正、删除提示作为独立事件呈现，不冒充新的参与者发言；首版对远端评论的编辑与删除仍在 Multica 完成。

Paseo 0.15.3 实际导入时，notification 映射未保留 provider 稳定 ID，首次重放会暂时重复任务描述，因此描述改用稳定 ID 的 `task-description` 插件行及 Markdown renderer，参与者消息仍只来自评论。插件行只带有界预览，全文按需分页读取，并以已有连接映射与描述版本避免跨版本拼接；缓存读取依靠宿主鉴权，CLI 离线、退出登录或切换 profile 时仍可读取旧连接缓存。恢复已有历史遵守 `history: skip`，既有原生通知保持原样。
