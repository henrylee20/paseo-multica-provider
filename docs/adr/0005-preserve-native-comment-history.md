# 保留原生评论消息并追加更正记录

现有外部 provider 接口不支持任意替换或删除原生 user/assistant 历史消息，因此不能同时保留原生消息语义并承诺远端编辑、删除原位反映到这些记录。
首版选择原生消息：远端评论编辑时追加更正内容，删除时追加删除提示，保留原消息，而不将所有评论改为可替换的插件卡片。
状态变化与更正、删除提示作为独立事件呈现，不冒充新的参与者发言；首版对远端评论的编辑与删除仍在 Multica 完成。

任务描述也不是参与者评论。Paseo 0.15.3 的实际导入验证发现，原生 notification 映射没有保留 provider 的稳定 ID，首次导入／重放会暂时出现重复描述。描述改用稳定 ID 的 `task-description` 插件行，由客户端 Markdown renderer 展示；恢复已有历史时遵守 `history: skip`。插件行只带有界预览，超长内容显式按需分页读取，RPC 核对当前连接与描述版本，避免超过 64 KiB 插件行限制或混合不同版本的全文。已经保存的旧通知属于既有原生历史，不尝试改写或删除。
