# 仅在具备去重保证时自动重试评论

一次评论可能触发远端执行，网络超时又不能证明评论未保存，因此盲目重试会重复发言或执行。
同一次投递使用稳定请求编号与不变的正文和目标，先查询回执；仅在已验证服务提供去重保证且仍在有效期内自动重试。
超过保证期限、服务不支持或结果仍无法确认时保留待核实状态，由用户核实后决定是否重发；评论保存回执不等于执行触发或进程结束的确认。

#10 的投递记录先于宿主 admission 保存不变输入、连接和目标、时间、停止 epoch、clientMessageId 与随机 UUID key。普通首次 POST 即带 Idempotency-Key，但这本身不是服务已支持去重的证据；本切片不自动重试。HTTP 5xx、超时、断线及无法校验的成功回执都保留 pending_verification，确定拒绝和发出请求前的失败保存 failed。收到的评论 ID、作者、父目标、来源时间与可选 trigger_outcomes 单独保存；trigger_outcomes 也不替代真实 Run 状态。

原生 `prompt.steer` 的承诺是已接收输入，远端结果由独立插件行报告。实际 0.15.3 会将 failed 或错误 turn ID 转为 interrupt 后替换，因此在任何 await 前缓存当前聚合 turn UUID，并在持久接收后返回这个 ID，即使该周期已结束或后续周期开始。每轮 turn ID 仍唯一，不复用已完成 ID。若插件存储故障导致输入根本未能持久接收，运行中只用匹配 ID 阻止意外取消，明确追加原生未接收错误且不发 HTTP；不能声称已持久保存或已发表。全局存储故障可能连宿主错误记录也无法落盘，界面不作持久保证。

停止 epoch 在首次 POST 领取前使用原值校验，不为旧记录刷新 epoch。进程重启后未确认记录只恢复本地输入／状态展示，不重复 POST；未来 #11 的回执恢复与重试必须沿用这份不变记录和 StopCoordinator.guardDelivery，并先验证服务真实去重能力及期限。


#11 在每次可能自动重试的核对中，先用实际服务的 `GET /api/issues/{id}/comments/idempotent` 做权威读取。只有 `Idempotent-Replayed: true`、作者／Issue／根目标／评论类型／不可变正文均匹配的成功回执才能证明能力；对已知保存的 anchor 还校验原评论 ID。单次带 key 的 POST 成功、通用 404 或单纯的“无回执”响应均不能证明支持。证明限定同一连接和 Multica 工作区，每轮重新核查，不持久信任服务版本或旧能力标记。先查原请求，若回执存在就关联原 clientMessageId；没有回执且本轮取得正面证明，才允许一次同 key 自动重试。

7 天上限以最初接收时间保守计算，达到边界就不再 POST；lookup 超期查无记录不证明从未发表。key 原样使用，非空、无首尾空格且 UTF-8 最长 255 字节。服务指纹不含正文，因此每次保存回执也要逐字检查原正文；远端编辑导致不一致时保留待核实，不把新正文套到旧输入。原始工作区 ID、连接、Issue、根、正文、时间、native delivery 与 Stop epoch 保持不变。任何自动 POST 都在重新检查当前 CLI 上下文后，通过原 epoch 的持久 Stop 栅栏立即发出；后续 Stop 不重新分配旧输入的 epoch。

回执不支持、读取失败、目标冲突、删除冲突、过期或一次安全重试后仍缺回执时，原子保存 pending_verification 与停止自动恢复的标记。自动重试响应仍丢失时，下一轮只允许再核实回执，不再做第二次自动 POST。重启后的已领取输入沿用同一恢复路径；旧身份缓存仍可列出与读取，但远端动作必须重新验证其原连接。

管理页的“核实原投递”仅做读取，从不 POST；显式“重新发送”先提示可能重复发言和触发执行，确认后才创建独立新 UUID key、clientMessageId、当前接收时间与 Stop epoch，并用 retryOf 关联旧请求。原记录和正文均保留。一次用户决定带稳定 requestId，RPC 响应丢失后的相同决定不会创建另一条新请求。切换 CLI 身份不能将该动作转发到新服务或账号。保存评论仍不表示 Run 已启动。

公开贡献／provider／RPC 测试使用临时 CLI、可控时钟与具备真实回执语义的隔离 HTTP 服务，覆盖保存后丢响应与正常重启、重复请求、先核实再重试、7 天边界、删除冲突、旧服务、回执不可用、正文排除边界、Stop 竞态、CLI 变化和明确新重发。编译后的管理页验证只读核实和二次明确决定。真实服务的能力验证和原生宿主验收由母规格统一记录，隔离服务测试不替代该证据。
